# 10 — System Frameworks Codification

Type: framework document

## Position in Evolution Framework

System Frameworks are the second stage in the progression from personal capability to scalable impact:

```
Identity → System Frameworks → Structuring → Adaptation → Leadership
```

## What System Frameworks Are

Codified intellectual assets that transform personal capability into repeatable, scalable processes. They are built through:
- Extensive research and observation of real-world organizations
- Academic study and practitioner insights
- Reverse engineering of high-performing individuals' capabilities
- Documentation of reproducible workflows, heuristics, and decision processes

## Key Principle

Performance must not depend on innate ability alone. Every capability worth acquiring should be decomposed into:
- Principles (why this works)
- Decision processes (when to apply)
- Heuristics (quick evaluation rules)
- Workflows (step-by-step execution)
- Environmental conditions (when this succeeds vs. fails)
- Feedback loops (how to know it's working)

## Transition Marker

Completion of System Frameworks marks the shift from:
- Isolated construction → public execution
- Building in private → demonstrating publicly
- Personal capability → institutional process

The frameworks provide competence at scale but cannot replace the individual's role in representation, decision-making, and leadership. The final stage of the Evolution Framework requires moving beyond system building into active embodiment and leadership of the value created.

## CE Integration

Each System Framework maps to a CE governance document, skill, or operational spec. This document (10) is the registry that tracks which frameworks have been codified and where they live in the workspace.
