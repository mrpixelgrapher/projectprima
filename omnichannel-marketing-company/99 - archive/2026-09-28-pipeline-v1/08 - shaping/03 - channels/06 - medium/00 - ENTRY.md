# Medium republish

**Purpose:** a condensed, executive-summary version for readers searching the topic on Medium, with a canonical link back to the hub.

## Contract

- **Reads:** `08-shaping/01-seeds.md` (core insight, process); `08-shaping/02-hub-article.md`; `00-brief.md` (voice).
- **Writes:** `08-shaping/03-channels/medium.md`.
- **Done when:** the version meets every rule below.

## Procedure

1. **A different title from the hub,** framed as an executive summary ("What HR should know about…").
2. **Length:** 800–1,500 words, rewritten from the seeds and the hub. Not a cut-down copy.
3. **Structure.** The core insight up front, then the process in brief, then one example, then a pointer to the full piece on the hub.
4. **Canonical link to the hub.** Record in the metadata how it is set on the platform [VERIFY: current Medium method, query-bank Q14].
5. **Image slot:** reuse the hub's `featured` slot. Note it in the metadata.

## Output template

The metadata block (add `Canonical: <hub URL placeholder>`), the title, then the body.

## Self-check

- [ ] Is the title different from the hub's, and is the length 800–1,500 words?
- [ ] Is the canonical link recorded?
- [ ] Is no paragraph copied from the hub?

## Traps

- **Posting the hub article again.** That is duplicate content that competes with the hub.
