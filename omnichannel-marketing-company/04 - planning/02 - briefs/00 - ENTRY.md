# 02 · Briefs

**Purpose:** write one brief per piece containing everything a child task needs, so that it can be researched, drafted, reviewed and shaped without ever opening the parent. The parent moves on, so a link to it would break. The brief carries what the child needs instead.

## Contract

- **Reads:** `04-planning/01-content-plan.md`; `02-discovery/05-client-brief.md`, `04-voiceprint.md`; `03-strategy/*.md`; `CONTEXT.md`; `piece-brief-template.md` in this folder.
- **Writes:** `04-planning/briefs/<piece-slug>.md` (one per row of the plan) and `04-planning/02-brief-index.md`.
- **Done when:** every plan row has a brief with every template section filled, and the index lists them all.

## Procedure

1. **Copy `piece-brief-template.md`** once per piece, into `04-planning/briefs/<slug>.md`, using the slug from the plan.
2. **Fill every section by copying, not summarising,** where the template says *copy*: the buyer profile, the pillar, the voiceprint, the words to use and never use, and the limits. The child's drafter needs the exact text.
3. **Fill the piece-specific sections** from the plan row: the question, stage, role, format, keyword candidate, links (by slug), start week and channels.
4. **Image slots.** List the image slots each channel in the plan requires. `08 - shaping/04 - visuals/00 - ENTRY.md` has the slot table.
5. **CTA.** One call to action that serves the objectives, e.g. "book a sample call", "request the corporate catalogue".
6. **Write the index:** one row per brief, giving the slug, role, question and start week.

## Output template

Use `piece-brief-template.md`. The index:

    # Brief index — <task id>
    | Slug | Role | Question | Start week | File |

## Worked example

Gemstone task, brief `real-or-fake` *(illustrative)*: the question is "How can a firm tell a real gemstone gift from a fake?"; the stage is considering; the pillar is P2, "Every stone can be verified" (proof: a lab report with each piece [client]); the buyer profile (HR lead) is copied in full; the voiceprint is copied in full; the CTA is "request the corporate catalogue"; the links go to `why-gifts-get-ignored`.

## Self-check

- [ ] Does every plan row have a brief, and does the index list them all?
- [ ] Could a drafter write the piece from the brief alone, without the parent?
- [ ] Are the buyer profile, pillar and voiceprint copied verbatim?

## Traps

- **"See the parent brief."** The child can't see it. Copy.
- **Briefs that prescribe the argument.** The spine is built at `05 - research` from research. The brief gives the question, not the answer.
