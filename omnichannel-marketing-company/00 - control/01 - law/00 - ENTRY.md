# 01 - law

**Purpose:** the rules every node and every task obey. Each rule lives here, and only here; stages point to it.

| File | What it fixes |
|---|---|
| `TASK_CONTRACT.md` | What a task folder is: layout, IDs, tags, states, moving, the client folder, and where each node may write |
| `ROUTES.md` | The ordered nodes of each route (engagement, month), and which steps run only when the proposal includes them |
| `HANDOFFS.md` | Every exchange with the outside world (client, operator, ARENA, image factory, motion): what goes out, who carries it, where the return lands |
| `BRIEF_SLOTS.md` | The 13 facts every job needs, when each is first needed, and how each slot's status is judged |
| `INSTRUCTION_STANDARD.md` | The folder convention, and the seven parts every stage ENTRY must have |
| `OMNICHANNEL_ENFORCEMENT.md` | One source → channel-shaped variants → every channel in the plan. Publish-kit rules 1–4 |
| `PERFECTIONISM_ENFORCEMENT.md` | Every artifact a client sees must name its crafted surplus |
