# 03 — Multi-Platform Content Decomposition

Type: workflow template

## Principle

One research effort → one long-form article → many platform-native derivatives. Not syndication (same content everywhere) but translation (same insight, different register).

## Decomposition Process

### Step 1 — Extract Derivation Seeds

From the published long-form article, extract:

| Seed Type | What It Is | Example |
|---|---|---|
| Core insight | The single most important claim | "Research-first production eliminates superficial content" |
| Process breakdown | How the result was achieved | "Phase 1: expand boundary, Phase 2: compress inward" |
| Contrarian angle | What this challenges | "Drafting IS the problem, not writing skill" |
| Data/framework | A reusable model or structure | "The diamond model of knowledge acquisition" |
| Implication | What changes because of this | "Your content calendar is a trap" |
| Visual concept | Something that can be diagrammed | "Visible 10% vs Hidden 90% iceberg" |

### Step 2 — Map Seeds to Platforms

| Platform | Best Seeds | Native Register |
|---|---|---|
| LinkedIn | Core insight + data/framework | Professional authority, evidence-based |
| Twitter/X | Process breakdown + contrarian angle | Methodology exposure, thread format |
| Threads | Implication + core insight | Conversational, discussion-provoking |
| Instagram | Visual concept + core insight | Carousel, clean graphics |
| Medium | Core insight + process breakdown | Condensed long-form, executive tone |
| Facebook | Implication + core insight | Accessible, educational, mature audience |

### Step 3 — Write Platform-Native

Each derivative must pass this test: "Would a native user of this platform find this content natural, or does it read like a repost?"

**LinkedIn:** Professional tone. Lead with the insight. Support with evidence. End with a question or call to reflection. 200-400 words. 1-2 graphics.

**Twitter/X:** Thread format. First tweet is the hook (contrarian or process). Subsequent tweets break down methodology. Final tweet links to the full article. 5-12 tweets.

**Threads:** Discussion-oriented. Open with the implication. Invite response. 100-300 words. 1 strong graphic.

**Instagram:** Visual-first. Carousel (5-10 slides) or single infographic. Each slide = one seed. Caption expands the visual. Bio link to full article.

**Medium:** Executive summary angle. 800-1500 words. Different title from Substack. Canonical link pointing to Substack as the original.

**Facebook:** Educational framing. 300-600 words. Accessible language. Strong opening image. Direct link to newsletter.

## 30-Day Deployment Framework

| Week | Focus | Content Types |
|---|---|---|
| 1 | Core insight exposure | All platforms: main derivative published |
| 2 | Process deep-dive | Twitter thread, LinkedIn case study, Instagram carousel |
| 3 | Implications & discussion | Threads follow-up, LinkedIn poll, Facebook discussion |
| 4 | Framework application | Instagram visual, Twitter mini-thread, LinkedIn framework post |

Each week exposes a DIFFERENT dimension of the same research — not repeated promotion of the same message.
