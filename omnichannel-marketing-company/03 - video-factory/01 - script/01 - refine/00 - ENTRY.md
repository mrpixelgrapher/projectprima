# 01 · Refine

**Purpose:** make each script shootable and sharp: the hook lands in 3 seconds, every beat earns its seconds, every frame is picturable, and the words sound like the client.

## Contract

- **Reads:** `25-writing/<P>/scripts/<V-id>.md` (every video); the piece brief (format, voice, language); `23-performance/03-virality.md` (hooks first); `21-discovery/06-voiceprint.md` (month task: `clients/<client>/voice.md`).
- **Writes:** `31-script/<V-id>-shooting-script.md` (one per video); `31-script/00-video-index.md`.
- **Done when:** every video has a shooting script whose frames cover every second, whose read-aloud time fits the length, and whose every frame names what is shown.

## Procedure

1. **Index the videos:** V-id, piece, platform, length, aspect, language.
2. **Refine, beat by beat,** keeping the writing's argument (never adding a claim):

   | Test | If it fails |
   |---|---|
   | Does the hook say and show the stake within 3 s? | Rewrite the first line; move the strongest image to frame 1 |
   | Does each beat carry exactly one idea? | Split or cut |
   | Can every frame be pictured by someone who hasn't read the piece? | Replace abstractions with objects, people, actions |
   | Does the voice-over sound like the voiceprint read aloud? | Re-voice the line |
   | Does the call to action name the destination's one action? | Fix it to the brief's CTA |

3. **Timing:** voice-over at about 2.5 words per second; add 0.5 s of breath per beat change. Total within the platform length.
4. **Frame list:** renumber the storyboard frames F1, F2 … with start time, duration, what is shown, on-screen text, and the move to the next frame, as the writing gave it (the shots node designs it in full).

## Output template

    # Shooting script <V-id> — <P> · <platform>, <length>, <aspect>, <language>
    ## Beats
    | Beat | Start | Duration | Voice-over | On-screen text | Visual intent |
    ## Frames
    | Frame | Start | Duration | Shows | On-screen text | Move to next |
    Read-aloud time: … s · Changes from the writing script: …

## Worked example

*(illustrative)* V2a hook, before: "Many companies struggle with gift authenticity." After: "Your festival gift might be fake." (0–2.2 s), with frame F1 showing two identical blue stones.

## Self-check

- [ ] Does every frame say what is shown, concretely?
- [ ] Does the read-aloud time fit?
- [ ] Is every change from the writing script listed?

## Traps

- **New claims in refinement.** The argument was reviewed in writing; refinement tightens, it doesn't add.
