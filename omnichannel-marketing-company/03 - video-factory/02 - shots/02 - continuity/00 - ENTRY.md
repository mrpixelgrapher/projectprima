# 02 · Continuity

**Purpose:** keep every shot of every video looking like one piece of work: the same product, the same person, the same light and palette, so that stills generated one by one still cut together.

## Contract

- **Reads:** `32-shots/*-shot-list.md`; the client's ASSETS (product photos, brand colours); `25-writing/stills/` (the month's post stills, for visual consistency with the posts).
- **Writes:** `32-shots/01-continuity.md`.
- **Done when:** every recurring element has one reference description (and a reference image when the client supplied one), and every keyframe is listed with the references it must match.

## Procedure

1. **Recurring elements:** every product, person, place and prop that appears in more than one shot. For each: one description precise enough to render the same way twice (shape, material, colour, size, distinguishing marks), and the reference image if the client supplied one.
2. **The look:** one palette (3–5 colours), one light setup per location, one style; matching the month's post stills unless the plan says otherwise.
3. **Keyframe list:** every keyframe from the shot lists, with the elements and look it must match. This is the stills node's work list.

## Output template

    # Continuity — <task id> · <month>
    ## Recurring elements
    | Element | Reference description | Reference image | Appears in shots |
    ## The look
    Palette · light · style
    ## Keyframes
    | Keyframe | Shot | Must match |

## Worked example

*(illustrative)* `Sapphire A · a 2.1-carat oval, deep cornflower blue, a small inclusion at 4 o'clock, on a 14k white-gold desk stand · reference: from-client/product-photos/sapphire-a.jpg · shots V2a-S1, S3, S5`.
